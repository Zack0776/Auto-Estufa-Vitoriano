# Auto Estufa Vitoriano — site

Estático (HTML/CSS/JS). Não precisa de Node nem build.

- `index.html`, `css/style.css`, `js/script.js`, `js/car3d.js`, `assets/`, `models/car.glb`
- WhatsApp: constante `WHATSAPP_NUMBER` e `GOOGLE_MAPS_URL` no topo de `js/script.js` (já com (11) 98405-5055).
- Three.js e GSAP vêm de CDN. Abra por um servidor (Vercel, Netlify, GitHub Pages ou `python3 -m http.server`); abrir o arquivo direto (file://) bloqueia o módulo 3D.
